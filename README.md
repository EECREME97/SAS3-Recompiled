# ⚔️ Swords and Sandals III — Recompiled

An unofficial native ARM64 Linux recompilation of the original Swords and Sandals III Flash game, developed for retro handheld consoles.

Originally developed and tested on the **TrimUI Brick running NX Redux**.

## Features

- Native ARM64 execution without Ruffle
- Full 640 × 480 rendering
- Optimized CPU rendering and graphical caching
- Original combat mechanics and progression
- Music and combat sound effects
- Persistent gladiator saves
- Equipment and inventory management
- D-pad virtual mouse controls
- Medieval gauntlet cursor
- Optimized town and battle performance

## Supported devices

| Device | Status |
|---|---|
| TrimUI Brick — NX Redux | Tested and playable |
| R36S | Untested |
| RG35XX series | Untested |
| TrimUI Smart Pro | Untested |
